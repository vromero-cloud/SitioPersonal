Recursos Tecnológicos del Curso

Para potenciar tu aprendizaje y capacidad de análisis, utilizaremos dos herramientas fundamentales que son estándar en la ingeniería térmica:

Escritura y Cálculo Simbólico

Scientific WorkPlace / Notebook

Es la herramienta definitiva para la creación de documentos científicos. A diferencia de un procesador de texto común, este permite integrar matemáticas complejas con facilidad.

  • Calidad Editorial: Genera archivos PDF con formato de libro de texto.
  • Cálculo Simbólico: Resuelve integrales, derivadas y álgebra de forma analítica.
  • Visualización: Crea gráficas en 2D y 3D para analizar el comportamiento de funciones termodinámicas.

Tip: Úsalo para tus tareas; la claridad de tus desarrollos matemáticos mejorará notablemente tu calificación.

Simulación y Propiedades Termofísicas

EES (Engineering Equation Solver)

EES es mucho más que un resolvedor de ecuaciones; es una base de datos termodinámica masiva e interactiva.

  • Tablas de Vapor Automáticas: Olvida las interpolaciones manuales. Obtén cualquier propiedad ($h, s, u, v$) con una sola línea de código.
  • Fluidos Reales: Incluye datos para refrigerantes, amoníaco, gases JANAF y aire psicrométrico.
  • Análisis Paramétrico: Permite realizar estudios de "qué pasaría si..." variando una propiedad y viendo el efecto en la eficiencia del ciclo.
  • Optimización: Encuentra las condiciones de operación ideales para un sistema térmico.

¿Estás listo para instalar estas herramientas? Puedo ayudarte con los conceptos básicos de sintaxis para que empieces tu primera práctica.
